This project is a FastAPI application that stores one collection of movies inside a SQLite database and then serves it over a HTTP.main.py defines the endpoints, while database.py handles the SQL storage, and the data_pipeline folderholds the reusable validation/cleaning functions we used in MP1. The GET/movies/search filters and sorts movies using SQL, while the POST/movies/process validates and cleans the data (movies) and then saves the result. GET/movies is cached in FakeRedis for 90 seconds, with a separate entry for each limit. Every upload and successful processing run will clear the cache so that retrievals never return old data. Since the data lives in SQLite, it survives server restarts, while the cache does not.
